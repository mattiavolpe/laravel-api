## 2026-08-23 - Prevent IDOR in Controller Methods Using Implicit Route Model Binding
**Vulnerability:** Insecure Direct Object Reference (IDOR) vulnerabilities exist in the `show`, `edit`, `update`, and `destroy` methods of `app/Http/Controllers/Admin/ProjectController.php`. These methods use implicit route model binding to retrieve the `Project` model but fail to verify if the currently authenticated user is the owner of the project.
**Learning:** The architectural pattern of relying on implicit route model binding without implementing explicit authorization checks (like Laravel Policies or manual ownership checks) allows users to access and manipulate resources belonging to other users by modifying the resource ID in the URL.
**Prevention:** Always enforce strict ownership verification in controller methods that handle user-specific resources, preferably by checking `$model->user_id === auth()->id()` (or using Laravel Policies) before allowing the operation to proceed.
