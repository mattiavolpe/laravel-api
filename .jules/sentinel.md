## 2024-05-05 - Admin Controller IDOR Vulnerability
**Vulnerability:** Insecure Direct Object Reference (IDOR) vulnerabilities were present in `ProjectController`, `TechnologyController`, and `TypeController`. Users could view, edit, update, or delete other users' data because ownership validations were missing in controller methods while implicit route model binding was used without corresponding Laravel Policies.
**Learning:** The application routes map directly to controllers relying on implicit route model binding, but does not implement Laravel Policies for these models. Therefore, ownership constraints defined during `store` were not enforced during other actions (`show`, `edit`, `update`, `destroy`).
**Prevention:** Explicitly enforce ownership constraints at the beginning of each relevant controller method using `$model->user_id != auth()->id()` to reject unauthorized access. Alternatively, establish and implement Laravel Policies uniformly across user-owned models.
