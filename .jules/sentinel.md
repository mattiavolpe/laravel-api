## 2024-04-08 - Implicit Route Model Binding IDOR Vulnerability Pattern
**Vulnerability:** Insecure Direct Object Reference (IDOR) due to missing explicit ownership checks in controller methods using implicit route model binding (e.g., `show`, `edit`, `update`, `destroy` in `ProjectController`, `TypeController`, `TechnologyController`).
**Learning:** The application lacks a centralized authorization mechanism (like Laravel Policies) for user-owned models (`Project`, `Type`, `Technology`). Implicit route model binding automatically resolves and injects models into controller methods based on the URL parameter, regardless of whether the authenticated user owns them. Without explicit checks, any authenticated user can access, modify, or delete resources belonging to other users simply by changing the ID or slug in the URL.
**Prevention:** Always implement explicit ownership checks (e.g., `if ($model->user_id != auth()->id()) abort(403);`) within controller methods when utilizing implicit route model binding for user-owned resources, unless access is governed by properly configured Laravel Policies or global scopes. When doing these checks, use the loose `!=` comparison to prevent false positives from type mismatches.
