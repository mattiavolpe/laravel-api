## 2024-04-14 - IDOR Vulnerability via Implicit Route Model Binding\n**Vulnerability:** Insecure Direct Object Reference (IDOR) on Project, Type, and Technology endpoints.\n**Learning:** Implicit route model binding in Laravel fetches the model by ID but does not automatically authorize ownership, requiring manual checks or explicit Policies.\n**Prevention:** Always implement explicit ownership checks (`if ($model->user_id != auth()->id()) abort(403);`) or use Laravel Policies when exposing user-owned resources.
