## 2024-05-24 - Missing Authorization on Controller Methods (IDOR)
**Vulnerability:** The codebase lacked proper authorization checks in controller methods like `show`, `edit`, `update`, and `destroy` for the `Project`, `Type`, and `Technology` models. This allowed users to potentially access, modify, or delete resources belonging to other users by manipulating object IDs (Insecure Direct Object Reference).
**Learning:** The architectural pattern used relies on implicit route model binding without implementing Laravel Policies. This makes the application susceptible to IDOR unless explicit ownership checks (e.g., `if ($model->user_id !== Auth::id()) abort(403);`) are manually enforced in the controller methods.
**Prevention:** Always implement explicit ownership or authorization checks (such as using Laravel Policies or checking `$model->user_id !== Auth::id()`) when accessing or modifying resources that belong to a specific user, especially when using implicit route model binding.
