## 2024-05-18 - Fix Insecure Direct Object Reference (IDOR) vulnerabilities in Admin Controllers
**Vulnerability:** IDOR vulnerabilities in `ProjectController`, `TypeController`, and `TechnologyController`. Authenticated users could view, edit, update, or destroy projects, types, and technologies belonging to other users.
**Learning:** The codebase relies heavily on implicit route model binding without Laravel Policies. When you do route model binding like `public function show(Project $project)`, Laravel automatically fetches the project based on the ID/slug in the URL, but it DOES NOT verify that the `$project` belongs to the currently authenticated user.
**Prevention:** If an application's architecture utilizes implicit route model binding without global Policies, explicitly enforce ownership checks at the controller level (e.g., `if ($model->user_id != auth()->id()) abort(403);`) on any endpoints modifying or viewing user-owned models. Keep in mind to use loose comparison (`!=`) instead of strict (`!==`) when comparing string/int casting from database.
