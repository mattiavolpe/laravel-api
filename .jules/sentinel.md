## 2024-04-10 - Implicit Route Binding IDOR Vulnerability
**Vulnerability:** The application was vulnerable to Insecure Direct Object Reference (IDOR) attacks because Laravel's implicit route model binding automatically resolves models from the database based on the ID in the URL, but the controllers (`ProjectController`, `TypeController`, `TechnologyController`) lacked explicit authorization checks to ensure the currently authenticated user actually owned the resolved model before displaying, editing, updating, or deleting it.
**Learning:** While implicit route binding is convenient, it bypasses authorization. If standard Laravel Policies are not implemented and applied via middleware or controller helpers, explicit ownership verification (e.g., comparing `$model->user_id` with `auth()->id()`) must be manually enforced in every controller method that handles a specific model instance.
**Prevention:** Always implement Laravel Policies and authorize resource access (e.g., `$this->authorize('view', $model);`) or manually verify ownership against `auth()->id()` whenever implicit route binding is used for user-owned models. Use loose comparison (`!=`) when comparing with `auth()->id()` to prevent strict type mismatch errors.
