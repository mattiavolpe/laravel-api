## 2024-04-20 - Missing Authorization in Implicit Route Binding
**Vulnerability:** Insecure Direct Object Reference (IDOR) on Project, Type, and Technology controllers.
**Learning:** The application relies heavily on implicit route model binding without implementing Laravel Policies or Requests for authorization logic. While Types and Technologies are user-owned (indicated by the `user_id` property and BelongsTo relationship), the controllers lacked explicit checks, exposing them to IDOR. Also, automated reviews might falsely flag fixes that treat Type and Technology as user-owned due to standard assumptions about typical Laravel architectures.
**Prevention:** Always verify if a model is user-owned by checking its `$fillable` array and relationships (e.g., `user()`). Ensure explicit ownership checks (like `if ($model->user_id != auth()->id()) abort(403);`) are manually enforced in controller methods where Policies aren't implemented. Use loose comparison (`!=`) instead of strict (`!==`) when comparing Eloquent model IDs with `auth()->id()` to prevent false-positive 403s.
