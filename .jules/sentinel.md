## 2024-05-27 - Fix IDOR in ProjectController
**Vulnerability:** Insecure Direct Object Reference (IDOR) in `ProjectController` (`show`, `edit`, `update`, `destroy` methods). The controller methods do not verify if the currently authenticated user is the owner of the `Project` model being accessed.
**Learning:** Laravel's route model binding automatically fetches the model based on the route parameter, but it does not automatically authorize access based on ownership unless explicit policies or authorization checks are implemented. In this codebase, the implicit route model binding in controllers like `ProjectController` makes the application susceptible to IDOR vulnerabilities if explicit ownership checks are not manually enforced.
**Prevention:** Always implement explicit authorization checks (e.g., using Laravel Policies or manual ownership checks like `if ($model->user_id != auth()->id()) abort(403);`) in controller methods that handle actions on specific models, especially when using implicit route model binding.
