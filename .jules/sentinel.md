## 2024-05-15 - Missing Authorization Checks (IDOR)
**Vulnerability:** Insecure Direct Object Reference (IDOR) vulnerabilities exist in the admin controllers (`ProjectController`, `TypeController`, `TechnologyController`) where resources (Projects, Types, Technologies) are accessed via implicit route model binding, but no ownership verification is performed before exposing, modifying, or deleting the resource.
**Learning:** The application uses implicit route model binding which automatically fetches the model instance by ID, but does not apply Laravel Policies by default. Consequently, any authenticated user can access or modify other users' resources by guessing the ID.
**Prevention:** Always implement explicit ownership checks (e.g., `if ($model->user_id != auth()->id()) abort(403);`) in controller methods (`show`, `edit`, `update`, `destroy`) when route model binding is used without policies. Use loose comparison (`!=`) instead of strict comparison (`!==`) to avoid 403 errors due to type mismatch.
