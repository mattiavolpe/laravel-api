## 2025-04-28 - [Insecure Direct Object Reference (IDOR) via Implicit Route Model Binding]
**Vulnerability:** Insecure Direct Object Reference (IDOR) across user-owned resource controllers (ProjectController, TypeController, TechnologyController).
**Learning:** The application heavily relies on implicit route model binding without implementing standard Laravel Policies for authorization. This pattern inherently exposes models to unauthorized access unless explicit ownership checks (e.g., `if($model->user_id != auth()->id()) abort(403);`) are manually enforced inside every relevant controller method (show, edit, update, destroy). Automated code review systems may flag these checks with false positives due to type mismatches (strict comparison vs string casting from DB).
**Prevention:** Whenever implicit route model binding is used for user-owned models instead of Laravel Policies, ensure that explicit ownership authorization checks using loose comparison (`!=`) are immediately added to all methods accessing or modifying the bound instance.
