## 2024-05-24 - [Avoid Loading Entire Tables into Memory for Aggregates]
**Learning:** In Laravel, fetching all relationship models into memory (e.g., `Auth::user()->projects()->get()`) just to compute count, newest, or oldest entries causes massive performance degradation and potential memory exhaustion on large datasets. Instead, database-level aggregates like `count()`, `latest()->first()`, and `oldest()->first()` should be used. Furthermore, chaining these methods onto a relationship call like `Auth::user()->projects()` mutates the underlying query builder. To prevent unintended side-effects across multiple aggregate queries on the same relationship, invoke the relationship freshly for each operation.
**Action:** Always use database-level queries (`count`, `max`, `min`, `first`) instead of pulling entire collections into PHP memory when calculating aggregates. Ensure to invoke relationship methods anew for each query to prevent builder state mutation.
