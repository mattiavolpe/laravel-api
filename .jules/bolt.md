## 2024-07-09 - Inefficient Eloquent Model Counting
**Learning:** Checking for model existence using \`count(Model::where(...)->get()->toArray()) > 0\` is an anti-pattern in Laravel. It causes Eloquent to execute a \`SELECT *\` query, hydrate full model objects for every matching row, convert the entire collection into a memory-heavy array, and then count the array in PHP. This can lead to severe memory exhaustion and slow response times if the table has many records.
**Action:** Use \`->exists()\` to check if any records match, which executes a highly optimized \`SELECT exists(SELECT 1...)\` query directly at the database level and returns a boolean without loading data into memory. If checking for specific counts (e.g. \`> 1\`), use \`->count()\` which executes a lightweight \`SELECT COUNT(*)\` query.
