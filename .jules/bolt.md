## 2024-06-25 - Use Database Queries Instead of PHP Collections for Aggregate Checks
**Learning:** In Laravel/Eloquent, checking for record existence or counting records using `count(Model::where(...)->get()->toArray())` or similar is an anti-pattern that heavily hits backend performance. It unnecessarily loads all matching database records into PHP memory, hydrates them as models, converts them to arrays, and then runs `count()` in PHP. For large datasets, this can cause significant memory exhaustion and lag.
**Action:** Always use `->exists()` or `->count()` directly on the query builder (`Model::where(...)->exists()`). This delegates the checking/counting entirely to the database, skipping memory overhead entirely, and fetching just a single scalar boolean/integer value.
