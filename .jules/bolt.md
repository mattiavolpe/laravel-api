## 2024-06-25 - Avoid loading full record sets into memory for existence/count checks
**Learning:** Found a common anti-pattern in Laravel controllers (e.g., `TechnologyController`, `TypeController`, `ProjectController`) where `count(Model::where(...)->get()->toArray())` was being used to check for record existence. This is highly inefficient because it executes the query, hydrates a full collection of Eloquent models, converts them to arrays, and loads them into PHP memory just to count them.
**Action:** Always use `->exists()` directly on the query builder for fast database-level existence checks (returns a boolean and runs a swift `SELECT EXISTS` query). Use `->count()` on the query builder when counting the exact number of matching rows without loading records into memory (runs a `SELECT count(*)` query).
