## 2024-05-24 - [Avoid Loading Entire Tables into Memory for Aggregates]
**Learning:** In Laravel, executing `$collection = Model::get(); count($collection)` or accessing `$collection[0]` loads all rows into memory, severely increasing memory usage for large tables. Furthermore, chaining multiple aggregate methods on the same relationship method (e.g., `Auth::user()->projects()`) without `clone` mutates the single shared query builder instance, leading to incorrect queries on subsequent calls.
**Action:** Always use database-level aggregations (`Model::count()`, `Model::latest()->first()`) to minimize data transfer and memory usage. When reusing a relationship query builder for multiple distinct queries, clone the instance (e.g., `(clone $query)->count()`) to prevent query pollution.
